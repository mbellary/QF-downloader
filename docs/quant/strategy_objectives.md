# Q0.5 — Strategy Objectives

Machine-readable authority: `docs/quant/strategy_objectives.yaml`.

## Goal

Define the trading intent so downstream decisions are auditable. Objectives must be measurable and must include both targets and explicit prohibitions.

## Required components

- Trading style and instrument scope
- Measurable targets (risk-adjusted performance, drawdown, turnover)
- Explicit non-goals / prohibitions to prevent metric gaming

## Alignment

Objectives must not contradict system KPIs, loss constraints, or feature constraints.
